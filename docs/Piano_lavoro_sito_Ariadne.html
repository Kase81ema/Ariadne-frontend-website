    Premesse

      Come si usa

      1. Ogni task principale si apre con un clic: dentro ci sono le sottotask da spuntare, la prova di fatto, le dipendenze e uno spazio per le note.
      2. Lo stato di un task si cambia dall'etichetta colorata (da fare → in corso → fatta → bloccata) o dal menu nel dettaglio.
      3. Le modifiche restano nel browser di questo computer. Per portarle con te o passarle al nuovo account Claude usa Salva file aggiornato: scarica una copia di questo stesso file con lo stato dentro, da sostituire nella cartella Website Ariadne.
      4. Il Gantt è a settimane: le barre piene sono task in corso, quelle vuote sono da fare, le barre a righe sono bloccate, i rombi sono le milestone. Passando sopra una barra si evidenziano le task da cui dipende.
      5. Claude può aggiornare direttamente questo file nel repository: i dati stanno in un unico blocco JSON in fondo alla pagina.
