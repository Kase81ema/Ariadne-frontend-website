# Ariadne — Sito Consumer v10

Sito web consumer di Ariadne SRL, scuola italiana di coaching creativo-esperienziale.

## Struttura

```
├── homepage.html          # Hub principale
├── approccio.html         # L'approccio (ex "Il metodo")
├── scuola.html            # Hub Scuola — proposta di valore annuale
├── il-tuo-percorso.html   # Diagramma percorsi ICF (sotto Scuola)
├── coaching-atelier.html  # Community (sotto Scuola)
├── laboratori.html        # Laboratori Ariadne (sotto Scuola)
├── webinar.html           # Presentazioni e testimonianze (sotto Scuola)
├── core-coaching.html     # Modulo Core Coaching
├── advanced-coaching.html # Modulo Advanced Coaching
├── team-coaching.html     # Modulo Team Coaching
├── core-quadrant.html     # Certificazione Core Quadrant® Ofman
├── training.html          # Hub Training esperienziale
├── training-lsp.html      # Training Lego® Serious Play®
├── training-kaospilot.html# Training Kaospilot Masterclass
├── workshop.html          # Workshop brevi
├── calendario.html        # Calendario eventi
├── area-riservata.html    # Area riservata alumni
├── ariadne.css            # CSS condiviso (variabili, pattern)
├── ariadne.js             # Animazioni (fade-in, parallax)
├── revisione.css          # Editor di revisione (opzionale)
├── revisione.js           # Editor di revisione (opzionale)
├── CONTEXT.md             # Contesto progettuale completo
└── assets/                # Logo, cubotti, foto
```

## Menù principale
L'approccio · Scuola · Core Quadrant® · Training · Workshop · Calendario

## Note per Design
Il file `CONTEXT.md` contiene tutto il contesto progettuale: palette, font, regole visive, terminologia, struttura dei percorsi, prezzi, tono di voce. Leggerlo prima di iniziare qualsiasi lavoro grafico.
